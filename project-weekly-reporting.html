Manual

Business problem

Before this automation, the weekly lead recap reporting process relied heavily on manual steps across multiple tools — extracting data from LeadPortal, preparing Excel reports, and manually drafting partner emails.

The initial preparation stage alone typically took around one hour each week, involving repetitive tasks across different systems that were time-consuming and prone to human error — incorrect file naming, misplaced files, outdated data, or inconsistent report preparation.

  • Filtering partner data and date ranges in LeadPortal manually
  • Manually updating Excel reporting files and recreating pivot tables
  • Manually saving, renaming, and navigating files across folders
  • Manually drafting individual partner emails in Outlook

Solution

I developed a Streamlit-based workflow automation tool that guides the user through the reporting process and automates all repetitive preparation tasks — ensuring the workflow runs in a structured and repeatable way every week.

The application serves as a single-entry point for the entire weekly pipeline, from OAuth authentication through to the Excel report being open and ready for partner distribution.

My contribution

I designed and implemented the full automation layer using Python, Streamlit, Power Query, and VBA — integrating a modern data extraction workflow with the existing Excel-based reporting process without disrupting the team's structure.

  • Designed the Streamlit interface to guide users through each step
  • Implemented Databricks SQL connection using OAuth authentication
  • Automated file archiving and export workflows with dynamic file naming
  • Integrated the workflow with the existing Excel VBA reporting template
  • Added progress indicators, status messages, and dataset previews
